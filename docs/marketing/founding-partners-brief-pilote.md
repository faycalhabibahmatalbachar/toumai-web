# Fiche de cadrage — pilote Founding Partners

**Modèle non contractuel.** Ne pas saisir de données personnelles dans le dépôt public. Conserver la version signée et les informations des interlocuteurs dans un espace privé autorisé.

| Champ | À documenter avant tout essai |
|---|---|
| Organisation / responsable | À confirmer |
| Problème / public cible | À décrire |
| Objectif du pilote | À décrire |
| Baseline vérifiable | Valeur et méthode de mesure |
| Indicateur de succès | Seuil validé par le partenaire |
| Données autorisées | Origine, licence, confidentialité, suppression |
| Fonctionnalités incluses | Liste explicite |
| Fonctionnalités exclues | Liste explicite |
| Canaux et langues | À confirmer |
| Validation humaine | Rôle et fréquence |
| Durée | Début, fin et possibilité d'arrêt |
| Plafond FCFA | Limite écrite, coûts couverts, responsable |
| Sécurité | Accès, journalisation, incidents, sauvegarde |
| Réversibilité | Export/suppression et fin des accès |
| Contrat / autorisations | Références des documents signés |
| Résultat / bilan | Données réelles uniquement |
| Décision | GO / ITERATE / STOP et justification |

**Stop immédiat** si dépassement du budget, donnée non autorisée, incident de sécurité, réponse critique non supervisée ou retrait du consentement applicable. La présente fiche n'est pas un contrat, un devis ou une garantie de résultat.
